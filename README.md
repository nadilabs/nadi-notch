# Nadi

An adaptive notch for Windows.

This repository contains the [Nadi website](https://nadilabs.github.io/nadi-notch/), built with HTML, CSS, and vanilla JavaScript.

No framework or build step required.

## Local preview

```bash
python -m http.server 4173
```

Open [localhost:4173](http://localhost:4173).

The site is set up for GitHub Pages deployment from the `main` branch.
