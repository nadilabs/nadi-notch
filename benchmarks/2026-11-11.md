## Measurement definitions and limitations

- **Working Set (MiB):** resident physical memory used by the process, including shared pages. It is *not* a measure of uniquely owned RAM. Values use **MiB** (1 MiB = 1,048,576 bytes), not decimal MB.
- **Private Bytes (MiB):** privately committed process virtual memory; do not interpret this as physical RAM.
- **CPU (% total machine):** Nadi process CPU time divided by sample elapsed time and the four logical CPU count. A sampled median of 0% does **not** imply the process never consumes CPU.
- **P95:** 95th percentile among approximately one-second samples, by trial; maxima are the highest observed samples.
- **UI states:** Resting, Expanded, Music and Shelf70 were confirmed by the person running the benchmark. The script does not inspect the rendered UI, media state or File Shelf contents. The 70-file count was confirmed by the operator. The Music scenario used browser playback as reported by the operator.
- **Single-machine evidence:** These results do not establish general behavior on other CPUs, operating systems, workloads, display scales, or Nadi builds. This test does not measure startup, power consumption, battery impact, network usage, background browser memory, or long-term leaks.
- **Repeatability:** For broader performance claims, run three 120-second valid trials per mode on more than one Windows PC and report between-machine variation.
